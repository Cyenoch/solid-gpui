Date: 2026-08-30 (evidence completed 2026-08-31)  
Repository revision: `c329b63d38b3c444d37b3dcfb2d37a024b43eca5`  
Scope: Rust/Cargo dependency graph and distributed host archive; Bun/npm lockfiles and package contents; Apache-2.0 release metadata.

## Executive verdict

**STOP publication.** The default `react-gpui-host` graph reaches three pinned
Zed crates whose manifests declare `GPL-3.0-or-later`, and two pinned Zed crates
have no manifest `license` field. A release owner and legal reviewer must
decide whether and how the host can be distributed before push, registry
publication, signing, notarization, or other external distribution.

The blocker is recorded in
[`issues/01-gpl-and-unknown-host-licenses.md`](issues/01-gpl-and-unknown-host-licenses.md).
This is a legal decision, not an engineering waiver. No dependency was
changed, no license was selected for another copyright holder, and no
third-party notice was fabricated. `cargo deny check licenses` remains
strict and red. The existing Makefile `audit` target remains advisories-only
and was not modified.

## Default host reachability evidence

`crates/react-gpui-host/Cargo.toml` has `default = []`, but its `gpui`,
`gpui-platform`, and `react-gpui` dependencies are ordinary non-optional
dependencies. Only `embedded-bun` is optional. The pinned `ztracing` manifest
has ordinary `zlog.workspace = true` and `ztracing_macro.workspace = true`
dependencies. GPUI source uses `#[ztracing::instrument(skip_all)]` on
`parse_svg` and `render_parsed`, so the edge is used, not merely declared.

Target-qualified commands with no dev dependencies succeeded:

```text
cargo tree -p react-gpui-host --target aarch64-apple-darwin \
  --no-dev-dependencies -i zlog
zlog -> ztracing -> gpui -> gpui_apple [build-dependencies] -> gpui_macos
  -> gpui_platform -> react-gpui-host
zlog -> ztracing -> gpui -> react-gpui -> react-gpui-host

cargo tree -p react-gpui-host --target aarch64-apple-darwin \
  --no-dev-dependencies -i ztracing
ztracing -> gpui -> gpui_apple [build-dependencies] -> gpui_macos
  -> gpui_platform -> react-gpui-host
ztracing -> gpui -> react-gpui -> react-gpui-host

cargo tree -p react-gpui-host --target aarch64-apple-darwin \
  --no-dev-dependencies -i ztracing_macro
ztracing_macro -> ztracing -> gpui -> gpui_apple [build-dependencies]
  -> gpui_macos -> gpui_platform -> react-gpui-host
ztracing_macro -> ztracing -> gpui -> react-gpui-host

cargo tree -p react-gpui-host --target x86_64-unknown-linux-gnu \
  --no-dev-dependencies -i self_cell
self_cell -> cosmic-text -> gpui_wgpu -> gpui_linux -> gpui_platform
  -> react-gpui-host
```

The feature tree showed `react-gpui-host feature "default"`, `gpui feature
"default"`, and default features for `ztracing`, `zlog`, and
`ztracing_macro`. A locked release build for `aarch64-apple-darwin` exited 0;
its linker map contained a `react_gpui_host...ztracing...rcgu.o` object. A
successful build is not license approval.

Other weak-license reachability is target-sensitive. `cbindgen` (`MPL-2.0`)
is a GPUI Apple build dependency reaching the macOS host graph; `option-ext`
(`MPL-2.0`) reaches the native font-kit graph; `dwrote` (`MPL-2.0`) appears in
the all-target Windows-capable graph; both `r-efi` versions appear through
all-target `getrandom` paths but not the active macOS trace. File-scope,
linking, notice, source, and relocatable-object obligations require legal
review where applicable.

## Release action

Before removing the STOP warning, the release owner and legal reviewer must:

1. Decide permitted treatment of `zlog`, `ztracing`, and `ztracing_macro` under
   GPL-3.0-or-later.
2. Resolve the absent manifest license fields for `gpui_shared_string` and
   `gpui_util` with the copyright holders.
3. Confirm `self_cell`'s Apache option and review weak-copyleft conditions.
4. Re-run the inventory against the exact source revision, host artifact, and
   exact npm tarballs intended for distribution.
5. Produce required notices, source offers, corresponding-source, or
   relinkable-object materials before publication.

No dependency, `deny.toml`, Makefile, package manifest, or publication command
was changed by this audit. The tracked release checklist now carries the
corresponding STOP warning.
