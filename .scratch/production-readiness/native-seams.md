# Native accessibility and lifecycle implementation seams

Date: 2026-09-07. Research only; no dependency updates or production edits.
Source versions: linked gpui-pre 0.3.3, AccessKit 0.24.1, accesskit_macos 0.26.3 from [Cargo.lock](../../Cargo.lock:40). Findings are source-backed feasibility, not a compiled prototype or desktop qualification.

## Accessibility: a small existing public seam is sufficient

**Correction to the earlier audit:** absence of `aria_live` and `aria_disabled` builders does not make these semantics an upstream blocker. GPUI exposes mutable AccessKit nodes through its public synthetic-child hook. The older [live-region investigation](../a11y-second-pass/issues/02-live-regions.md) and [capability audit](capability-audit.md) overstate the need for an upstream change. No GPUI fork, whole-crate vendoring, or speculative upgrade is needed for the primitive renderer path.

The cleanest implementation is inside the existing [apply_accessibility helper](../../crates/solid-gpui/src/renderer/paint/accessibility.rs:20):

1. Continue assigning the role, stable accessibility ID, label/value and existing state.
2. Attach `StatefulInteractiveElement::a11y_synthetic_children(move |builder| ...)`.
3. Call `builder.parent_node()` and apply `set_disabled()`/`clear_disabled()` and `set_live(accesskit::Live::Polite/Assertive/Off)` to the **existing node**.

[Public callback setter](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-0.3.3/src/elements/div.rs:1343) accepts an owned `FnOnce(&mut A11ySubtreeBuilder)`. [Public parent_node](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-0.3.3/src/window/a11y.rs:360) returns `&mut accesskit::Node`, expressly documented as the parent node. [Element prepaint pipeline](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-0.3.3/src/element.rs:414) calls this hook after element prepaint and before popping/publishing that same node. This does not add a synthetic child, layout box, node identity, or event listener. AccessKit provides [disabled flag setters](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/accesskit-0.24.1/src/lib.rs:1816) and [live property setters](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/accesskit-0.24.1/src/lib.rs:2139).

**Composition constraint:** the callback setter replaces its existing callback; it does not append. The current primitive paint/accessibility helper and primitive text-input implementation have no synthetic-child registrations (reviewed all renderer matches). Do not blindly apply the helper over a third-party editor that already owns such a callback. Native generated controls remain a separate integration review.

If callback composition later becomes necessary, the alternate principled seam is a typed `Element` decorator which delegates the inner element's `id`, source location, request_layout/prepaint/paint, role, and synthetic children, and adds properties in `write_a11y_info`. [Element accessibility hooks](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-0.3.3/src/element.rs:112) and [Stateful<E> forwarding implementation](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-0.3.3/src/elements/div.rs:3966) are direct precedents. Keep the same `GlobalElementId` and call the inner trait methods directly; do not wrap an already-erased `AnyElement` in a new semantic container. The inner focus path uses that [same global ID](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-0.3.3/src/elements/div.rs:2279), as do [accessibility actions](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-0.3.3/src/elements/div.rs:2545). A decorator is unnecessary for the immediate primitive helper and has more code to maintain.

### Live text and verification

A live flag alone is not a useful announcement contract. The **linked macOS adapter** announces `node.value()`, not arbitrary labels: [announcement payload](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/accesskit_macos-0.26.3/src/event.rs:35). It emits on [added nodes with value and live](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/accesskit_macos-0.26.3/src/event.rs:236) and on [updated value/live/filter state](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/accesskit_macos-0.26.3/src/event.rs:298). An initial implementation can explicitly pair the new live enum with existing `accessibilityValue`; examples must update the value. Do not promise that changing a label or any nested text automatically announces. Decide whether higher-level Text should derive its announcement value in a later, explicit contract.

A semantic role and element ID are required before the hook runs. Existing generic role maps to no AX node, so `View accessibilityLive=...` without an actual supported role cannot announce. Expose/validate the supported combination and keep identity stable; do not silently invent an offscreen child. Disabled semantics describe state; actual pointer/keyboard/focus behavior must continue to follow native disabled behavior.

Suggested key acceptance: canonical live enum → generated wire → stored node, one regression proving disabled true/false and live/value reach the same AccessKit node while existing role/value/children remain, and one real VoiceOver status update. The ordinary headless platform does not activate the OS AccessKit tree, so do not call a node-property unit test screen-reader qualification.

## Native application events: exact hooks and actual platform limits

| Hook | Exact linked API | Implications |
| --- | --- | --- |
| Open URLs | `Application::on_open_urls<F>(&self, callback: F) -> &Self`, `F: 'static + FnMut(Vec<String>)` | Callback receives no `&mut App`; queue to the existing foreground/registry path. [API](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-0.3.3/src/app.rs:270) |
| Reopen | `Application::on_reopen<F>(&self, callback: F) -> &Self`, `F: 'static + FnMut(&mut App)` | Can directly update app/weak registry once initialized. [API](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-0.3.3/src/app.rs:280) |
| Window closure | existing `App::on_window_closed` callback in host | The current runner unconditionally quits when registry says last Surface closed. [Host callback](../../crates/solid-gpui/src/host/mod.rs:966), [registry result](../../crates/solid-gpui/src/host/mod.rs:812). |

Register application hooks **before `.run`**, where [run_profile constructs the Application](../../crates/solid-gpui/src/host/mod.rs:929). `HostProfile::initialize(&mut App)` alone is too late a seam for these `Application` methods. Establish an application-owned bounded activation queue before the run closure, attach the registry consumer when initialized, and drain after the Solid application is ready. Application events must outlive any one Surface if the host supports zero-window residence; a new Surface should get a fresh Surface ID, not reuse a retired one.

**macOS:** both hooks have actual native callback call sites. [URL dispatch](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-macos-0.3.3/src/platform.rs:1421) converts NSURL absolute strings and invokes the callback. The implementation drops events when no callback is installed, another reason to register before run. [Reopen dispatch](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-macos-0.3.3/src/platform.rs:1337) invokes the handler **only if `has_open_windows` is false**. Thus `on_reopen` does not implement arbitrary second-launch notification while windows are already open. The inspected platform has `openURLs` registration, with no separate `openFiles`/`openFile` selector; document opening needs actual file-URL qualification, not assumed coverage from API naming.

**Windows/Linux:** the callback API exists, but inspection of the complete installed platform source found storage/setter references without corresponding invocation sites. See [Windows callback storage](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-windows-0.3.3/src/platform.rs:81), [Windows setter](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-windows-0.3.3/src/platform.rs:608), [Linux storage](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-linux-0.3.3/src/linux/platform.rs:108), and [Linux setter](/Users/jgbingzi/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/gpui-pre-linux-0.3.3/src/linux/platform.rs:396). Merely registering these hooks therefore does not establish Windows/Linux inbound delivery. Host-owned CLI activation and authenticated/appropriately scoped local IPC may be needed for second-instance forwarding, plus platform association setup. Do not advertise this as cross-platform based on the shared trait.

## Recommended scope

The primitive accessibility bridge can proceed immediately using `parent_node()`, followed by actual VoiceOver evidence. Add lifecycle policy and macOS activation as explicit supported capabilities; defer a cross-platform claim until Windows/Linux event delivery is implemented and tested. Keep OS registration, chosen URL schemes, document associations and single-instance product policy outside universal JSX contracts, while the host owns bounded typed delivery and lifetime.
