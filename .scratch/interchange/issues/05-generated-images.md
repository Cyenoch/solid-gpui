# Generated image data into the app

Status: resolved
Verdict: resolved-no-gap

## Question

How can an app display image bytes it generated without adding inline bytes or
data URLs to the image wire surface?

## Evidence

- The accepted image decision keeps source/fallback as host-local paths and
  explicitly rejects inline bytes/data URLs at
  `docs/adr/0007-explicit-image-path-source.md:8-23,25-35`.
- The native painter converts source strings to `PathBuf` and delegates loading
  to GPUI at `crates/react-gpui/src/renderer/paint/image.rs:38-55`.

## Decision and action

Use an app-owned host-visible temporary or sidecar file for generated bytes,
then set `Image.source` to that path. The existing host image cache and path
semantics remain intact, and the application owns temporary-file lifecycle.
Data URLs/base64 are rejected as scope creep: they require a new byte-bearing
wire contract and a second image loading path.
