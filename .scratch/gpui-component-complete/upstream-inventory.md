## 无法把 Rust 闭包直接发送给 JS 的接口

以下是从签名与执行阶段得出的桥接设计结论，不是现有 JS 实现说明。JSON/跨进程消息不能携带 `Fn`、`Entity<T>`、`&mut Window`、`&mut App`、`Context<T>`、`Action` trait object、借用 `ArcData<'a, T>` 或 Rust 泛型 delegate。同步 native render/paint/validation 回调也不能靠每帧阻塞 IPC 等 JS 结果。

## “所有组件可用”的最小交互验收边界

这是一份实现验收需求，当前文件没有运行任何 JS 支持检查，因此不提供通过结论。

1. **生成/安装链路**：公开 import/JSX/props/children/事件/commands 都必须在正常应用路径可用；名字能 import、空标签能 render 或 mock screenshot 不足以满足本清单。typed compound children 不能降格为任意 Div。
2. **生命周期**：节点 identity 稳定；父组件更新不重建 Input/Table/List/Tree/Dock state，不丢焦点、IME、选区、滚动、折叠、进行中的 drag；unmount 会取消/释放订阅和晚到请求。
3. **编辑与选择**：真实键盘与指针检查 Input/Textarea/Editor/Otp、Radio/Checkbox/Switch/Toggle、Select/Combobox、Calendar/DatePicker、ColorPicker、Slider；覆盖 disabled/readonly、keyboard focus、Change versus Confirm/Release/Complete。Select optional scalar 与 Combobox vector 不能混同。
4. **数据视图**：List/DataTable/Tree/VirtualList/MessageScroller 至少验证真实可见范围、滚动、搜索/懒加载、选中与右键；表格排序/列宽/列移动/单元格事件；消息 prepend 保锚点、append 尾随及用户上翻退出尾随。不能仅以一屏静态渲染当作完成。
5. **浮层与服务**：真实窗口 Root、trigger、Escape/Tab/focus restore、外部点击策略、Dialog veto、menu action/keyboard、notification 队列与 keyed remove、sheet resize；NativeMenu 的 OS action 回传实际触发。
6. **Dock**：真实 tabs/panel split/move/close/zoom/resize/tiles drag；保存、卸载、重建、load 后 panel payload/active 内容与布局相等；Panel lifecycle 事件的上游语义保持。DockArea 无 DockSkin 的“行为存在但无 chrome”不能当作 gpui-component 支持。
7. **Charts/Text**：7 种图表都运行真实非空数据；支持各自独有属性（OHLC、pie radii、radar 多 series/element label、Sankey topology）；上游支持的 tooltip 实际 hit test；TextView 保留 Markdown/HTML、选择/复制、链接事件、custom slots。
