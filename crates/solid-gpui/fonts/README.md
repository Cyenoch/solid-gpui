# Maple Mono

Unmodified Maple Mono v7.9 TTF files (standard ligature edition, without CN or Nerd Font additions).

Source: https://github.com/subframe7536/maple-font/releases/download/v7.9/MapleMono-TTF.zip
License: SIL Open Font License 1.1, reproduced in `MapleMono-OFL.txt`.

Regular, italic, bold and bold italic are embedded in both desktop and Web component hosts.
